## 教育测验模块

本项目集成了一个教育测验模块，用于展示知识问答功能。当前包含以下问题：

**问题：解放思想、实事求是是（ ）**
- A. 马克思主义精髓
- B. 毛泽东思想精髓
- C. 邓小平理论精髓
- D. 是党的工作作风

**正确答案：B. 毛泽东思想精髓**

解放思想、实事求是是毛泽东思想的精髓，也是中国共产党思想路线的核心内容。
